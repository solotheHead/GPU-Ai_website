    Description

    NX-G12 SP3 GPU server

    The NX-G12 SP3 combines a single AMD EPYC SP3 processor with configurable GPU, memory and storage options. Use the configurator to outline a system for AI inference, development, rendering or other GPU compute tasks.

    Configuration overview

    Platform 4U rackmount server; one AMD EPYC processor using Socket SP3.
    GPU configuration Up to 12 compatible dual-slot, actively cooled GPUs at PCIe 4.0 x8, or up to 6 compatible larger GPUs at PCIe 4.0 x16. The supported card count depends on the selected card and complete build.
    Memory DDR4 ECC registered memory; 16 DIMM positions, with a minimum configurator selection of 2 modules. Supported module type, population and total capacity are confirmed for the selected CPU and motherboard.
    Storage Optional M.2 NVMe storage; up to 2 drives can be requested through the configurator.
    Networking Configurable network card options. The selected adapter, ports and transceivers must match the deployment network.
    Operating system Optional Ubuntu Server installation and configuration.
    Included accessories Mounting rails and the listed power cable set are included in the configuration.
