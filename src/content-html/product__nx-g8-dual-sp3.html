    NX-G8 Dual SP3 GPU server

    Build a GPU server around two AMD EPYC SP3 processors and the memory, storage and graphics hardware your workload requires. The NX-G8 Dual SP3 configurator supports up to 8 GPU selections, with the final supported arrangement confirmed for the complete system.

    Configuration overview

    Processors Two AMD EPYC processors using Socket SP3; the configurator selects a pair of the chosen CPU model.
    GPU configuration Up to 8 compatible GPUs. Options include actively cooled workstation GPUs and passive server GPUs; suitability depends on the chassis airflow, card dimensions, power and full configuration.
    Memory DDR4 ECC registered memory; 32 DIMM positions, with a minimum configurator selection of 2 modules. Final memory population and supported capacity are confirmed in the quotation.
    Storage Optional M.2 NVMe and U.2 NVMe drive selections. Up to 2 M.2 drives can be requested. U.2 drive quantity and backplane requirements are confirmed in the quotation.
    Networking Configurable network card options for the required connectivity.
    Operating system Optional Ubuntu Server installation and configuration.
    Included accessories Mounting rails and the listed power cable set are included in the configuration.
