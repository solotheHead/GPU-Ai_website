Why these components

  • Memory equal to GPU memory. The balanced build has 768GB of system memory, the same as the GPUs, which makes loading large models and feeding data pipelines easier. Its 24 modules populate all 12 DDR5 channels of each EPYC 9004 processor for full memory bandwidth.
  • Eight CPU cores per GPU. Two 32-core EPYC 9354 processors leave headroom for data preparation, tokenisation and serving software. The entry build’s two 16-core EPYC 9124 processors suit inference where models are loaded once and the GPUs do the work.
  • Local NVMe. Model weights for 768GB of GPU memory are large; fast local storage shortens load times and holds datasets and checkpoints.
  • Networking for the workload. 100GbE suits fast data transfer or several servers working together; 25GbE is enough for a single inference server serving users.

What 768GB of GPU memory is good for

  • Serving several large models at once, for example multiple 70B-class models in 8-bit, each on its own GPU or pair of GPUs.
  • Very large models across all eight GPUs. Models with several hundred billion parameters can fit in 8-bit or 4-bit form using tensor or pipeline parallelism. The RTX PRO 6000 has no NVLink, so GPUs communicate over PCIe; this works well for inference but is slower than NVLink-connected systems for training a single large model.
  • Multi-team or multi-tenant use. With Multi-Instance GPU, each card can be divided into up to four isolated instances — up to 32 in one server.
  • Fine-tuning, rendering and simulation, where Blackwell’s FP4 and FP8 support, RT cores and video engines are useful.

Power, cooling and where it runs

The eight GPUs alone can draw up to 4.8kW, so the complete server needs more than 5kW at full load. Plan a rack position, power circuits and cooling for that load. The passive GPUs depend on strong front-to-back airflow, and the server is loud — a data centre or colocation facility is the right place for it. We confirm the power budget and power supply configuration in the quote and can arrange colocation in Bulgaria.

Alternatives

  • More memory bandwidth: eight H200 NVL GPUs give 1,128GB of HBM3e and NVLink between GPUs, at about $235,920 for the GPUs alone at indicative prices. See RTX PRO 6000 vs H200 NVL.
  • Lower budget: fewer RTX PRO 6000 GPUs now, with room to add more later in the same platform, or RTX 5090 32GB cards for models that fit in 32GB per GPU.
  • Single-socket or PCIe 4.0 platforms: our other 4U servers cost less but run PCIe 5.0 GPUs at PCIe 4.0 speed.
