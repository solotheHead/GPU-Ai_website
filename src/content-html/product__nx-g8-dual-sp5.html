    NX-G8 Dual SP5 GPU server

    The NX-G8 Dual SP5 configurator combines two AMD EPYC SP5 processors with DDR5 ECC memory and GPU options for AI inference, model development, rendering and other compute applications. Request the hardware combination suited to your software and deployment environment.

    Configuration overview

    Processors Two AMD EPYC processors using Socket SP5; the configurator selects a pair of the chosen CPU model.
    GPU configuration Up to 8 compatible GPUs. Available selections include workstation and server GPU options; the final combination is checked for card dimensions, power, airflow and platform compatibility.
    Memory DDR5 ECC registered memory; 24 DIMM positions, with a minimum configurator selection of 2 modules. Module compatibility, memory speed, population and total capacity are confirmed for the selected build.
    Storage Optional M.2 NVMe and U.2 NVMe drive selections. Up to 2 M.2 drives can be requested. U.2 drive quantity and backplane requirements are confirmed in the quotation.
    Networking Integrated dual 1GbE RJ45 networking is listed for this platform, with optional network card upgrades in the configurator.
    Operating system Optional Ubuntu Server installation and configuration.
    Included accessories Mounting rails and the listed power cable set are included in the configuration.
